
+ путь до копии: `/mnt/backup/copies/{NAME}/{DATE}/image/{DATA}`
+ пример пути: `/mnt/backup/copies/latest/image/БУНКЕР`
+ структура каталогов: [structure.md](structure.md)

### Возможности

1. [x] Удалить копии хранящиеся более 180 дней.
2. [x] не удалять папку `latest` даже после 180 дней.
3. [x] игнорировать файлы названия которых длиннее 255 байт.
4. [x] выводить ошибки при расчете различий.
5. [x] выводить список изменений между копиями.
